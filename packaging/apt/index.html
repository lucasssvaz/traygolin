Traygolin

Unofficial Linux tray app for the Pangolin VPN client. This is the apt repository for Ubuntu 26.04 or later (Libadwaita 1.9). Ubuntu 24.04 is not supported.

Install the Pangolin CLI first:

curl -fsSL https://static.pangolin.net/get-cli.sh | bash

Add this repository
